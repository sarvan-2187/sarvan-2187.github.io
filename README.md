# Bookmrk Landing Page

A high-fidelity, premium landing page for the **Bookmrk** Chrome Extension. Built with a focus on modern aesthetics, performance, and interactive storytelling.

## 🚀 Live Features

- **Interactive Before/After Slider**: A custom-built comparison tool showcasing the transformation from "Browser Chaos" to "Bookmrk Canvas".
- **Dynamic GitHub Integration**: Automatically fetches the latest release version and download links directly from the GitHub API.
- **macOS Aesthetic**: A premium UI featuring floating dock navigation, glassmorphism, and "Traffic Light" window controls.
- **Lenis Smooth Scroll**: Cinematic, high-performance inertial scrolling for a seamless browsing experience.
- **Interactive Bento Grid**: Modern feature showcase with dynamic hover effects and glass cards.
- **Keyboard Animation**: Visual demonstration of the `Ctrl + Shift + Y` instant capture workflow.
- **Direct Video Embed**: Integrated setup guide for a zero-click educational experience.

## Tech Stack

- **Core**: Semantic HTML5, Vanilla JavaScript (ES6+).
- **Styling**: Vanilla CSS3 with CSS Variables and advanced animations.
- **Typography**: [Stack Sans Text](https://fontsource.org/fonts/stack-sans-text) (Variable Font).
- **Icons**: [Lucide Icons](https://lucide.dev/) for a clean, professional look.
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/).
- **API**: GitHub REST API for dynamic versioning.

## Getting Started

Simply open `index.html` in any modern browser to view the landing page. No build steps or dependencies are required as everything is handled via high-performance CDNs.
