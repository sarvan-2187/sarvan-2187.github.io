Install Guide
01

Download the ZIP

Head to the GitHub Releases page and grab the latest bookmrk-vX.X.X.zip. No account, no install wizard.

02

Extract the Archive

Unzip to a permanent folder. Chrome reads the extension from this location — don't delete it after loading.

03

Load Unpacked in Chrome

Open chrome://extensions, enable Developer Mode, click Load Unpacked, and select the folder. Done.

Why sideloading? Because the Chrome Web Store reviews every update, can pull extensions at any time, and logs install analytics. Sideloading gives you a version that's permanently yours.

Zero Cloud

No accounts.
No tracking. No limits.

Every bookmark you save lives in your browser's local storage. Not on our servers. Not in anyone else's hands.

Local-First Storage

All data is stored using Chrome's local extension storage. Nothing is ever transmitted to an external server — there isn't one.

Fully Auditable

The entire source is on GitHub. Every single line. Skeptical about privacy claims? Read the code yourself and verify.

Store-Immune

Because Bookmrk is sideloaded, Chrome Web Store policy changes, forced updates, or store removals have zero effect on you.

Your bookmarks are none of our business.
We have no database, no analytics pipeline, no telemetry, no user accounts. Bookmrk is software that runs on your machine and reports to no one.
